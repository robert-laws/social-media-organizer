# Your images live here

Any file you put in this folder gets published with the site at:

```
https://robert-laws.github.io/social-media-organizer/images/<filename>
```

Example: upload `headshot.jpg` here, and its URL is
`https://robert-laws.github.io/social-media-organizer/images/headshot.jpg` —
paste that URL into the app (Settings → Profile photo, or a post's Cover image
field).

**Heads up:** this repo is public, so anything here is publicly visible.
That's fine for images you're posting to social media anyway — don't put
private photos here.

Tips: use lowercase filenames with hyphens (`ai-workflow-cover.jpg`), keep
files under ~500 KB (resize to ≤1600px wide), and prefer JPG for photos /
PNG for screenshots.
